# Planner and classifier experiments

This directory contains isolated linguistic planning/classification experiments.
They are not retrieval experiments, retrieval baselines, threshold calibrations or
policy promotions.

`PLN-EXP-0001-thin-intent-classifier` uses only the fictional Dolved Care
Engineering Benchmark V2 engineering/tuning split. Its raw structured values may
retain `BENCHMARK_TEXT`; this permission does not extend to customer corpora.
